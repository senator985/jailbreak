# GameMario PS4 Host Page (g2all Clone)

این پروژه یک کلون کامل، مستقل و ایزوله از صفحه **PS4 Host (g2all)** برای **گیمنت ماریو** می‌باشد.

## 📌 ویژگی‌های اصلی

* **تشخیص خودکار سیستم‌عامل و ویرایش Firmware (Firmware Detection):**
  پشتیبانی کامل از تمامی نسخه‌های فریم‌ور پشتیبانی‌شده در نسخه اصلی (5.05, 5.07, 7.00 - 8.52, 9.00 - 9.60, 10.00 - 11.02, 11.50 - 13.00).
* **برندینگ اختصاصی گیمنت ماریو:**
  * نام: **گیمنت ماریو**
  * شماره تماس: **09130018195**
  * لوگو رسمی GameMario به همراه بهینه‌سازی نمایش در تمام دستگاه‌ها.
* **پشتیبانی کامل از Offline Cache / Application Cache Manifest:**
  تمام فایل‌های manifest (`505.manifest`, `700.manifest`, `900.manifest`, `css.manifest`, `slopkit.manifest`) جهت نصب کش آفلاین بروزرسانی و تنظیم شده‌اند.
* **طراحی کاملاً کشسان (Responsive):**
  پشتیبانی از رزولوشن‌های مختلف از جمله دسکتاپ، تبلت و موبایل بدون ایجاد Horizontal Overflow.
* **بدون تغییر در منطق اکسپلویت و پی‌لودها:**
  کدهای حساس مربوط به اکسپلویت‌ها، کدهای زابیناری، پچ‌ها و پی‌لودهای سیستم دست‌نخورده باقی مانده‌اند.

## 📁 ساختار پوشه‌ها و فایل‌ها

```text
.
├── assets/                  # لوگو و دارایی‌های گرافیکی اختصاصی (logo.svg, logo.jpg)
├── 505/                     # فایل‌ها و اسکریپت‌های مربوط به فریم‌ور 5.05
├── 700/                     # فایل‌ها و اسکریپت‌های مربوط به فریم‌ور 7.00 تا 8.52
├── 900/                     # فایل‌ها و اسکریپت‌های مربوط به فریم‌ور 9.00 تا 9.60
├── css/                     # اسکریپت‌ها و پچ‌های فریم‌ور 10.00 تا 11.02
├── slopkit/                 # اسکریپت‌ها و پچ‌های فریم‌ور 11.50 تا 13.00
├── index.html               # صفحه اصلی هاست
├── cache505.html            # صفحه نصب کش برای فریم‌ور 5.05
├── cache700.html            # صفحه نصب کش برای فریم‌ور 7.00 - 8.52
├── cache900.html            # صفحه نصب کش برای فریم‌ور 9.00 - 9.60
├── cachecss.html            # صفحه نصب کش برای فریم‌ور 10.00 - 11.02
├── cacheslopkit.html        # صفحه نصب کش برای فریم‌ور 11.50 - 13.00
├── *.manifest               # فایل‌های کش آفلاین مرورگر PS4
├── style.css                # استایل اصلی و Responsive صفحه
├── img.jpg                  # تصویر پس‌زمینه
└── goldhen_2.4b18.10.bin    # پی‌لود اصلی GoldHEN
```

## 🚀 نحوه اجرا روی Web Server

1. فایل‌های پروژه را روی وب‌سرور خود (مانند Nginx, Apache یا Node.js static server) بارگذاری کنید.
2. آدرس هاست را در مرورگر کنسول PS4 وارد کنید.
3. بر اساس نسخه سیستم‌عامل کنسول، کش مربوطه به صورت خودکار نصب خواهد شد.
